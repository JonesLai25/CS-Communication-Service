Existing evidence: phase7-vm-guest-swap-retry.txt reached the real ResumeStore on the isolated 384 MiB guest data filesystem and was refused by the existing check free >= 512 MiB + reserved bytes + manifest size. A 384 MiB volume cannot meet that condition even if empty. The minimum logical data filesystem capacity is therefore strictly greater than 512 MiB plus filesystem metadata/reserved blocks, the installed runtime/test data already on that filesystem, and at least one manifest/ciphertext reservation. The exact minimum depends on the selected filesystem and populated fixture; 640 MiB is only a sizing candidate, not a measured sufficiency claim. The project test disk cap is 512 MiB and was not increased. No repeat VM attempt, safety-check bypass, host restart, or host ZFS change was made. A larger explicitly authorized dedicated virtual disk, or a different administrator-provided isolated layout that satisfies both the 512 MiB free reserve and existing test limits, is needed for the real-CS VM power-interruption acceptance.
